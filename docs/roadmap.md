## 0.2.0（完成，2026-09-29）

按分类列出 v0.2.0 的实际交付与后续项目。详见 `CHANGELOG.md`。

### 界面

1. **导航和页面层级（完成）。** 独立的新建转写、任务、文字稿入口；保留详情 URL，批量提交进入任务列表，完成后跳转文字稿并提示保存成功。
2. **模型选择栏与本地扫描（完成）。** CLI / Web 共用模型目录，按引擎切换默认；启动时只读扫描模型文件，支持手动刷新。区分文件状态与依赖安装状态，云端不扫描，缺失的可下载模型仍可选并提示首次下载。新配置默认 faster-whisper large-v3-turbo，旧配置保留。
3. **下载前确认（完成）。** TXT / Markdown / SRT 点击后显示站内确认弹窗，支持取消、Esc 和焦点恢复；确认后才下载。
4. **历史标题复制原链接（完成）。** 悬停或键盘聚焦显示独立复制按钮，触屏直接显示；复制不触发跳转，本地文件不显示。

### 任务与进度

5. **任务启动后可以中断（延期）。** 后续为任务服务和 Web API 增加取消能力，覆盖排队任务及下载、抽音频、识别阶段，并在任务详情和列表提供操作。
6. **轮询反馈与日志降噪（完成）。** 断连保留进度并重试，404 与处理失败分开展示；任务列表保留失败记录。只过滤正常轮询 access log，保留阶段、失败与启动日志。

### 识别

7. **新增 Qwen3-ASR（延期）。** 作为新的本地识别引擎接入，评估 0.6B / 1.7B 模型的依赖、硬件要求和中英文识别效果，再纳入模型选择。
8. **同一链接换模型时复用已有音频（延期）。** 为下载后的音频建立基于平台视频 ID 的缓存；更换模型重新识别时跳过重复下载和抽音频，同时保留 B 站字幕优先行为。

## 后续迭代（开发中，尚未发布）

- 任务中断：已实现排队与运行任务的协作式取消、Web 操作和重启恢复；待随本轮其他功能一同验收。
- 音频复用与换模型重转写：进行中。
- Qwen3-ASR 0.6B：待实现。

## 已知问题

- openai-whisper 转写中文时经常输出繁体、没有标点；已改用 faster-whisper 为默认引擎，并在 `language=zh` 时自动加简体中文提示词。openai-whisper 保持原样。
- 专业术语（如“线程池”）容易识别错，通过 `--prompt` 传入术语可明显改善；阶段 7 评测时量化。

## V1 验收流程

粘贴 B站 / 抖音链接 → 看到处理进度 → 拿到带时间戳的文字稿 → 点 Copy for AI → 粘贴给 ChatGPT / Claude 继续提问。
